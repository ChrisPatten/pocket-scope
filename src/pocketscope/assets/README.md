# Assets
This directory contains static data assets used by PocketScope, such as airport and runway GeoJSON files.

## Airport/Runway Data
- 'airports.geojson': Contains geographical data for various airports. Retrieved from [FAA ADDS](https://adds-faa.opendata.arcgis.com/datasets/faa::airports-1/about).
- 'runways.geojson': Contains geographical data for runways. Retrieved from [FAA ADDS](https://adds-faa.opendata.arcgis.com/datasets/faa::runways/about).

## US States
- 'us_states.geojson': Contains geographical boundaries for US states. Retrieved from [eric.clst.org](https://eric.clst.org/tech/usgeojson/).
